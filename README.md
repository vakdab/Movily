# Movily

Lampa (https://github.com/yumata/lampa) з інтерфейсом із плагіна Moon / Snack TV (https://github.com/vakdab/Lampa).

## Що змінено відносно оригінальної Lampa
- **Інтерфейс**: рідний вигляд Lampa підмінено плагіном `plugin/dist/moon-interface.js` (Snack TV, шапка, ліве меню, налаштування). Він підключається автоматично з `index.html` після `app.min.js`, додавати його вручну в «Розширення» не потрібно.
- **Без екрану завантаження**: прибрано заставку `.welcome`, текст кроків завантаження і анімоване лого входу.
- **Чиста адреса**: `push_state = false`, адреса не отримує `?card=...`, тому після повторного відкриття додатка відкривається головна, а не остання картка (стару адресу з `?card=` / `?component=` чистить `index.html`).
- **Без вибору мови**: `lampa_settings.lang_use = false`, мова за замовчуванням `uk` (і `tmdb_lang = uk`). Змінити мову можна в налаштуваннях.
- **Лого**: Movily (трикутник з літерою M) у `img/logo-icon.svg`, `img/logo.svg`, фавіконах, PWA-іконках і `og.png`; у шапці воно замінює бургер на кнопці меню (`plugin/src-modules/movily-brand.js`).
- **Лише мобільний веб-інтерфейс**: TV-режиму немає на жодному пристрої (`is_true_mobile` в `index.html`, режим плагіна зафіксований як iPad-стиль без «lite», вибір вигляду й типу навігації прибрано з налаштувань).
- Ядро Lampa (`app.min.js`, `css/`, `vender/` тощо) не змінювалось.

## Структура
- `index.html`, `app.min.js`, `css/`, `lang/`, `vender/`, ... : Lampa (yumata/lampa)
- `plugin/src-modules/` : модулі інтерфейсу
- `plugin/build.sh` : збирає `plugin/dist/moon-interface.js` (`cd plugin && ./build.sh`)

## Зовнішній плеєр SenPlayer і таймкоди

Модуль `plugin/src-modules/movily-senplayer.js`. На iPhone/iPad у браузері (не в Telegram) за замовчуванням плеєр SenPlayer (один раз на пристрій, змінюється в Налаштування > Плеєр). Модуль перехоплює запуск відео (`Player.listener 'create'`), скасовує штатний запуск Lampa і відкриває `senplayer://x-callback-url/play` зі стартовою позицією (`position`) та колбеками `x-success` / `x-cancel` / `x-error`, які ведуть на https-адресу сайту (`?sp=done|cancel|error`), бо `lampa://` у веб-версії не обробляється.

Таймкод: якщо SenPlayer передав у колбеку позицію (`position`, `time`, `currentTime` та подібні), вона записується в Lampa (`Timeline.update`, з прив'язкою до серії). Якщо ні, після повернення на сторінку показується вибір «Скільки переглянуто?» (25 / 50 / 75 / 90 % / до кінця). Усе, що повернув SenPlayer, видно в Налаштування > Інтерфейс > SenPlayer. Документації щодо колбеків SenPlayer немає, тому чи повертає він позицію, потрібно перевірити на пристрої.

## Telegram Mini App

Зовнішній плеєр у міні-апп: Налаштування > Інтерфейс > «Плеєр у Telegram» = SenPlayer (за замовчуванням «Вбудований»). Схему `senplayer://` спершу відкриваємо напряму; якщо Telegram її не пропустив і сторінка лишилась на екрані, з'являється вибір: відкрити посиланням, через Telegram `openLink` або дивитись у вбудованому плеєрі.

Модуль `plugin/src-modules/movily-telegram.js` працює лише всередині Telegram (поза ним нічого не робить): розгортає застосунок, вимикає закриття свайпом, фарбує шапку в чорний, передає безпечні відступи в CSS (`--tg-safe-*`). Відео грає вбудовано (`playsinline` на кожному `<video>`), плеєр завжди «inner» (зовнішні iOS/Android плеєри у вебв'ю Telegram не відкриваються), на час відео вмикається повний екран Telegram (`requestFullscreen`, Bot API 8.0+) і не гасне екран. Кнопка «Назад» Telegram закриває плеєр або повертає на крок назад.

## Трейлер у картці фільму

На сторінці фільму або серіалу трейлер сам запускається фоном (як у Prisma): через затримку плавно проявляється поверх постера, внизу лишається градієнт, справа вгорі з'являється кнопка звуку. Джерело те саме, що в Prisma: `luno.watch/api/tmdb/{movie|tv}/{id}/trailer` (гостьова сесія `/api/client/session`), відповідь це прямий mp4, який грає в `<video>` без Referer. Файл у Prisma невеликий (720p, ~0,8 Мбіт/с), тому на екрані додано SVG-фільтр різкості, легкий контраст і плівкове зерно, що маскує компресію. Після завершення трейлера повертається постер, через кілька секунд трейлер стартує знову.

Налаштування: Налаштування > Інтерфейс > «Трейлери»: вмикач «Трейлер у картці фільму», «Звук трейлера», «Затримка трейлера». Код: `plugin/src-modules/movily-trailers.js`.

## Запуск
Потрібен будь-який статичний веб-сервер, наприклад `python3 -m http.server 8080`, далі відкрити `http://localhost:8080`.
Docker: `docker build --build-arg domain={domain} -t movily . && docker run -p 8080:80 -d movily`

## Оновлення
- Інтерфейс: правка в `plugin/src-modules/`, потім `cd plugin && ./build.sh`.
- Lampa: замінити файли ядра файлами з yumata/lampa і повторно перевірити правки в `index.html` (блок «Movily»).

## Картинка в картинці (PiP)

Плагін `plugin/dist/pipfs.js` (на основі [pipfs](https://cevamnelampaplagin.github.io/sharewithothers/pipfs.js)) підключається з `index.html` автоматично. Кнопка PiP є на панелі програвача. Вікно працює як на iPhone:

- перетягується пальцем або мишею, після відпускання прилипає до найближчого кута;
- pinch двома пальцями (або колесо миші, або куточок знизу праворуч) міняє розмір;
- тап показує кнопки: пауза, закрити (зупиняє відео), на повний екран; подвійний тап повертає на повний екран.
